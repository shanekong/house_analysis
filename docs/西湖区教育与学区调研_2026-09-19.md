# 杭州市西湖区教育与学区调研（阶段一）

> 核验日期：2026-09-19  
> 范围：杭州市西湖区义务教育阶段，重点服务购房与入学决策  
> 口径：优先采用杭州市教育局、西湖区政府、西湖区教育局、西湖教育网和学校官网。学区边界以当年“入学早知道”及学校招生公告为准。

## 一页结论

1. **买到学区内住房不等于一定录取该校。** 公办小学按教育服务区招生，学区报名人数超过计划时，按“房、住、户一致优先”分类录取；同一类别超额时，学校另行制定排序规则，未录取者由区教育局统筹。[2026年行知小学招生方案](https://www.hzxhjy.cn/xzxx/xyzx/xygg/202605/t20260528_758900.shtml)
2. **西湖区公办初中多数不是简单按住宅直接划片，而是“对应联系小学＋毕业生住户情况”分配。** 因此判断一套房的教育链路，必须同时核验小学学区、该小学当前对应初中以及小学毕业当年的政策。
3. **民办未录取后回公办，会按“同类排序靠后”处理。** 热门公办学校存在被调剂风险，不能把民办摇号当作没有成本的尝试。
4. **落户年限不是全区统一的固定门槛。** 当同类“房户一致”人数超过招生计划时，学校才可能按落户时间等公平规则排序；往年最迟落户日期只能反映当年供需，不能作为未来承诺。
5. **官方预警也明确不得直接作为购房和迁户依据。** “入学早知道”2026年数据统计至2026年5月，并持续更新；绿色、黄色、红色分别对应低于90%、90%—100%、达到或超过常态招生计划。[杭州“入学早知道”](https://rxyj.hzedu.gov.cn/#/front)

## 1. 2026年招生核心规则

### 1.1 招生对象与时间

- 2026年小学适龄儿童一般为2019年9月1日至2020年8月31日出生、年满6周岁，或经批准缓学的儿童。
- 小学网上报名：2026年6月2日至4日；公办小学第一批核验：6月27日至28日；6月30日起第一阶段录取；7月6日起第二阶段录取和调剂。
- 小升初信息预登记：5月28日至30日；公民办初中选报：6月14日至15日；6月23日起公办初中分配、民办初中电脑派位。

来源：[杭州日报：2026杭州中小学招生细则](https://mdaily.hangzhou.com.cn/hzrb/2026/05/23/article_detail_1_20260523A017.html)、[西湖区学校2026招生公告](https://www.hzxhjy.cn/hzsjzxx/xydt/xygg/202605/t20260529_759306.shtml)

### 1.2 公办小学录取顺序

学区学额不足时，主要按以下类别依次录取：

1. 儿童户籍、父母户籍、家庭住房三者均在学区内且一致；或儿童户籍落在祖辈全产权住房、实际共同居住且父母在杭州市区无房。
2. 儿童自出生起落户祖辈全产权住房并共同居住，但父母在杭州市区另有住房。
3. 具有杭州市区户籍但不属于前两类。
4. 非杭州市区户籍、持西湖区有效签注《浙江省居住证》的儿童。

房产通常要求父母或父母与儿童享有100%产权份额。共有产权、祖辈房产、集体户、拆迁过渡户、人才及政策照顾对象应个案核验。

### 1.3 民办与民转公学校

- 公民办同步报名，民办学校报名超过计划数时电脑随机派位。
- 被民办录取后不再安排其他学校；民办未录取回公办时，排在直接报名公办学校的同类别儿童之后。
- 2026年公益中学、育才实验学校、钱塘外语学校继续按原方式招生，招生范围、报名和录取政策与民办学校相同。
- 2026年西湖区小学报名中，绿城育华、钱塘外语、育才实验报名超过计划，需电脑派位；之江外语实验、云谷学校报名未超过计划，一次性录取。[西湖区教育局2026报名公告](https://www.hzxhjy.cn/xhjyw/xjrd/202606/t20260624_760740.shtml)

## 2. 近年对购房影响较大的学区变化

### 2.1 文三路校区启用，老城区初中对应关系调整

2025年起，十三中教育集团文三路校区对应：

- 文三街小学；
- 学军小学求智校区。

十三中教育集团教工路校区对应关系调整为：

- 文一街小学文一校区；
- 行知小学学院路校区。

该变化是缓解原十三中教工路校区红色预警和办学空间压力的重要调整。[西湖区政府重大行政决策目录](https://www.hzxh.gov.cn/col/col1229564477/index.html)、[决策内容转载](https://hz.xuequfang.com/article/7195688)

### 2.2 省府路小学对应西溪中学

西湖区2025年正式作出省府路小学对应联系初中调整决策；2026年官方“入学早知道”显示其毕业生对口 **杭州市西溪中学本部**。[西湖区政府重大行政决策目录](https://www.hzxh.gov.cn/col/col1229564477/index.html)、[省府路小学官方查询页](https://rxyj.hzedu.gov.cn/#/schoolDetail?year=2026&schoolName=2133003557001&id=0)

### 2.3 之江、双浦、云谷板块教育资源扩容

- 学军小学云栖校区当前对应十三中教育集团云栖校区。
- 行知三小于2025年正式亮相，位于夏铜街200号，规划42班。2026年招生范围为东至长深高速、南至袁富路、西至科海南路、北至袁浦路，并承接原周浦学区部分生源。[行知三小2026招生方案](https://www.hzxhjy.cn/xzxx/xyzx/xygg/202605/t20260529_759258.shtml)
- 西湖大学附属学校为2026年新设公办九年一贯制学校，位于西湖大学云谷校区西侧；小学部服务区为东至数治路、南至红庙前港、西至西湖余杭交界处、北至杭长高速，当前主要包括熙海棠湾。[官方查询页](https://rxyj.hzedu.gov.cn/#/schoolDetail?year=2026&schoolName=L000000310001&id=0)

## 5. 购房核验清单

签约前至少完成以下核验：

- 在[杭州“入学早知道”](https://rxyj.hzedu.gov.cn/#/front)分别用“找小区”和“找学校”核对；
- 向学校确认具体小区、期数、楼幢和门牌是否属于当年服务区；
- 核对房屋登记用途、产权份额、交付状态和户籍能否实际迁入；
- 核对儿童、父母户籍及房产是否构成“房、住、户一致”；
- 查询目标校当年预警和近三年分流情况；
- 核对小学对应初中是否已经调整、是否为九年一贯制；
- 核对原业主户口迁出、学位占用及合同违约责任；
- 把“学区未录取/政策变化”写入购房风险情景，不把开发商、中介承诺作为官方依据。
